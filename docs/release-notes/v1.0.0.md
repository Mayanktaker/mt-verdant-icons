# MT Verdant Icon Pack 1.0.0

© Mayanktaker Computers & Web Development | https://mayanktaker.com

The icon and cursor packs now live in their own repository so they can be updated without
reinstalling the theme.

## What's new

- **Standalone downloads:** icons and cursors ship as a single archive you can install on any
  Linux desktop, with or without the theme.
- **One-command install and removal:** the included installer adds both packs to `~/.icons`,
  refreshes the icon cache and activates them. `--uninstall` cleanly removes them again.
- **Install only what you need:** `--icons-only` and `--cursors-only` skip the other pack.
- **More symbolic icons:** the pack now includes additional GNOME Shell and extension glyphs
  (coverflow, lockscreen, screenshot and window-list), while keeping every icon from earlier
  releases.

## Compatibility

- Same artwork, pack names and palette as the icons bundled with MT Verdant Nocturne 0.2.0.
- Existing installs under `~/.icons/MT-Verdant-Icons` and `~/.icons/MT-Verdant-Cursors` are
  replaced in place.

## Install

```bash
curl -sSLO https://github.com/Mayanktaker/mt-verdant-icons/releases/download/v1.0.0/mt-verdant-icons-v1.0.0.tar.xz
tar -xf mt-verdant-icons-v1.0.0.tar.xz
cd mt-verdant-icons-v1.0.0
./install.sh
```
