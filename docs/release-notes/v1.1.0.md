# MT Verdant Icon Pack 1.1.0

© Mayanktaker Computers & Web Development | https://mayanktaker.com

The pack now comes in two flavours: the classic dark look and a brand-new light look for bright
desktop themes.

## What's new

- **Light variant:** a full second set of icons and cursors — `MT-Verdant-Icons-Light` and
  `MT-Verdant-Cursors-Light` — with soft ivory surfaces and deeper green accents that stay crisp
  on light backgrounds. Every icon from the dark pack is included.
- **Choose at install time:** running the installer now asks whether you want the dark look, the
  light look, or both. Prefer flags? `--dark`, `--light` and `--both` do the same without asking.
- **Switch anytime:** with both variants installed, pick either one from GNOME Settings or your
  desktop's theme switcher. Installing both keeps the dark look active by default.
- **Light cursors included:** the cursor set gets the same treatment — an ivory pointer with a
  deep-green outline that reads well on light backgrounds.

## Compatibility

- The dark packs keep their names, colours and look; an existing install is simply replaced in
  place when you reinstall.
- `--uninstall` now removes every variant at once.

## Install

```bash
curl -sSLO https://github.com/Mayanktaker/mt-verdant-icons/releases/download/v1.1.0/mt-verdant-icons-v1.1.0.tar.xz
tar -xf mt-verdant-icons-v1.1.0.tar.xz
cd mt-verdant-icons-v1.1.0
./install.sh            # asks dark, light or both
./install.sh --light    # or pick directly
```
